# Snesticle by Jota
Para compilar, utilize o ambiente PS2SDK configurado. Execute 'make' na raiz.

Instalação:
1. Coloque o arquivo .elf no pendrive em mass:/APPS/.
2. Crie a pasta mass:/ROMS/SNES/.
3. Abra o OPL e inicie o executável.
O emulador roda no EE (Emotion Engine, CPU principal do PS2) e carrega os módulos via IRX (arquivos de drivers do sistema operacional do IOP).
